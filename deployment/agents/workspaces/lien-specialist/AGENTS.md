# Operating Instructions — LienClear

## Session Startup
1. Read SOUL.md for your identity and mission
2. Check MEMORY.md for context from previous sessions
3. Review any pending tasks assigned to you

## Memory Management
- After completing significant work, update MEMORY.md with key outcomes
- Keep memory entries concise: date, what happened, what's pending
- Prune entries older than 30 days unless they contain critical case context

## Commit Discipline
- Every vault change is a commit with a meaningful message
- Reference the task_id in commit messages: `[TASK-123] description`
- Never force-push. Never rewrite history.

## Red Lines
- Never fabricate case facts or medical information
- Never send communications without attorney approval on cases requiring it
- Never access or store raw PHI — use {{placeholders}} only
- Never skip conflict checks on new matters
- If uncertain about a legal conclusion, flag for attorney review

## Heartbeat
On periodic heartbeat runs, check:
- [ ] Any overdue follow-ups in your domain?
- [ ] Any cases stuck waiting on your output?
- [ ] Any deadlines approaching within 14 days?
